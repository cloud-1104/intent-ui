# 导航与数据浏览

按当前任务只读取相关部分。目录：导航与范围、工作台、集合视图、查找与筛选、详情、数据表达。

## 导航与工作范围

**适用条件**：多模块、多层级或跨对象工作流；单页工具无需照搬完整导航框架。

- 以用户任务和业务对象组织菜单；列表通常是稳定入口，某条记录的新增、编辑和详情从上下文进入。
- 当前页面显示名称、必要的对象标识和组织或环境范围。侧栏选中态、面包屑和页面层级一致。
- 跳转链接保留正常的浏览器打开、复制和返回行为；动作按钮不伪装成导航。
- 返回列表时恢复适用的筛选、排序和浏览位置；记录已被删除或页面失效时落到最近的有效位置并说明。
- 深链接应可直接进入；未登录时先登录并恢复允许的目标，无权限时给出实际可行的下一步。
- 多租户或环境切换明确显示当前范围；有未保存修改时先处理离开行为。切换后清除旧范围选择，不短暂闪现旧范围数据。

Cloudscape 依据：[侧栏导航](https://cloudscape.design/patterns/general/service-navigation/side-navigation/)强调按用户任务和信息架构组织入口。范围切换与会话恢复是本 Skill 的后台扩展。

## 工作台与仪表盘

**条件必需**：用户需要从跨模块待办、异常、趋势判断开始工作。若用户每天直接处理一个列表，该列表可以作为首页。

- 先确定页面回答什么问题以及用户下一步做什么，再选择指标；每个信息块都有任务意义。
- 待办入口展示与当前角色相关的可处理项；指标钻取应携带时间和筛选条件，目标页能解释口径。
- 指标有单位、时间范围、必要的时区和更新时间；缺失或加载失败不展示为零。
- 可配置布局仅在角色需求差异有价值时提供；默认布局应完成核心任务。不能把“可拖动卡片”当作后台必需能力。
- 实时场景说明更新频率、暂停方式和数据过期状态；自动刷新不能打断用户选取或阅读详情。

Cloudscape 依据：[服务仪表盘](https://cloudscape.design/patterns/general/service-dashboard/)区分监控、调查和信息获取任务，并按用户需要选择固定或可配置布局。

## 集合视图

**选择视图**：需比较结构化字段用表格；对象识别主要依赖图片或少量摘要时用卡片；需要连续查看多个对象时考虑列表加分栏详情。只为当前任务提供一种合适默认视图，多视图切换不是必需功能。

- 列优先支持识别对象、判断状态和执行任务。把当前可执行动作依赖的状态显示出来。
- 名称或编号可作为详情链接；行内按钮、复选框和链接的点击不会同时触发行跳转。
- 仅有批量任务或选择任务时提供复选框。行选择与“打开详情”语义分开。
- 常用操作可以直接暴露，低频操作放更多菜单。位置保持稳定，危险操作与常规操作可辨认。
- 排序只用于有意义的字段，显示方向及多列排序的优先级；作用于整个匹配集合而非只有当前页。
- 数据量需要分页时，变化筛选后回到有效页；删除最后一行后回退到仍有结果的有效页。没有总数接口时使用“已加载数量”或下一页，不编造总数。
- 列宽、截断和横向滚动不能使对象身份、状态或关键操作无法识别。需要全文时提供可键盘访问的完整内容。
- 只有长时间高频使用复杂表格时才考虑列显隐、密度、固定列等偏好设置。

Cloudscape 依据：[表格视图](https://cloudscape.design/patterns/resource-management/view/table-view/)、[上下文操作](https://cloudscape.design/patterns/general/actions/incontext-actions/)。上述分页边界和选择约定是业务适配。

## 查找与筛选

**条件必需**：用户需要定位某个对象或一组工作项，且浏览不足以可靠完成。

| 用户任务 | 首选方式 | 不需要自动增加的能力 |
| --- | --- | --- |
| 已知名称、编号或关键词 | 标明匹配范围的文本搜索 | 任意字段表达式 |
| 按状态、负责人、类型找工作集合 | 少量明确的筛选项 | 全字段高级筛选 |
| 多个字段和值联合排查 | 可见条件、运算关系和逐项移除的高级筛选 | 面向普通用户的查询语言 |
| 高频重复使用同一工作集合 | 在证据支持时增加保存视图 | 共享视图、收藏中心默认全上 |

- 明确搜索字段、精确或模糊匹配、多个条件之间的关系，以及查询是否需点击“查询”。昂贵查询可显式提交；即时查询避免每次输入造成界面跳动。
- 搜索、筛选、排序和导出的作用范围一致。服务端分页的数据不得只过滤本页而仍声称搜索全量。
- 已生效条件可见且可移除；“清空条件”和“恢复默认”分别说明结果。
- 无匹配时保留输入和筛选，提供修改或清除路径；不要当作首次无数据来引导新增。
- 往返详情时保留条件。确有分享需求且条件不敏感时可放入 URL；个人信息、密钥等不进入 URL。
- 切换筛选时明确处理已选对象；默认清除不再有效的选择并提示。若支持跨筛选选择，持续展示完整选择范围，不能让不可见记录悄悄进入操作。

Cloudscape 依据：[筛选模式](https://cloudscape.design/patterns/general/filter-patterns/)按查询复杂度选择形式；[筛选持久化](https://cloudscape.design/patterns/general/filter-patterns/filter-persistence-in-collection-views/)支持往返和分享，并提醒避免敏感 URL 数据。

## 详情与关联对象

**条件必需**：用户需要列表之外的信息才能判断或操作。信息已足够时可省独立详情页。

| 情况 | 交互选择 |
| --- | --- |
| 少量补充信息 | 展开行或轻量详情面板 |
| 高频连续检查多个对象 | 保留列表的分栏详情 |
| 长内容、复杂操作或需独立分享 | 有明确地址的详情页 |
| 同一对象有多个独立任务分组 | 按任务分标签，不把每几个字段拆成一个标签 |
| 关联资源复杂且需继续导航 | 对象摘要加关联集合入口 |

- 明确对象身份、当前状态及影响用户判断的更新时间。详情动作与列表动作遵循同一业务条件。
- 只读值采用可读内容，重要标识提供复制反馈；敏感内容按权限处理，不因为“详情”而扩大数据可见范围。
- 进入编辑前说明修改对象或局部范围；取消返回原来的详情位置。
- 关联对象链接保留返回路径；关联数量和摘要有各自加载、空值及失败状态。
- 历史仅在追踪变化对任务有价值时显示，标明操作者、时间、动作和结果，避免泄露敏感字段。

Cloudscape 依据：[资源详情](https://cloudscape.design/patterns/resource-management/details/)按任务和关联复杂度区分普通详情、标签详情和资源中心。

## 数据表达与图表

- 区分未填写、不适用、未知、零和加载失败；同一产品统一表达。
- 时间区分事件发生时间和更新时间；跨地域任务明确时区。金额、比例、数量显示单位和必要精度。
- 状态使用文字和适当视觉标记，不能仅靠红绿判断。给出业务状态而非只展示接口状态码。
- 只有趋势、分布或比较能改善判断时使用图表；精确核对用明细或数据表。图表提供必要的数值阅读方式。
- 钻取与导出继承明确的数据范围和权限；无数据、部分缺失和异常与正常零值分开。
- 图表和自动刷新遵循减少动态效果偏好，不用连续动画表达必须阅读的信息。

本节是通用后台表达约定，按已有领域口径适配，不擅自规定业务精度或时区。
