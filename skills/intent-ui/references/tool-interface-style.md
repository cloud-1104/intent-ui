# 工具型界面风格

适用条件：用户指定 NextLabs、LarkAgentX 或相近的工具界面作参考，或明确要求为高频工作台、运营控制台及其配套展示面定义视觉与交互风格。已有产品规范时，先列出要迁移的做法及例外，沿用已有语义令牌与组件契约。

本文规则为本 Skill 自有扩展，来自 NextLabs 与明确借鉴它的 LarkAgentX 两个产品案例的综合提炼，不是联合标准。短引用 `N1`、`L1` 等对应[工具型界面风格来源](tool-interface-sources.md)中的核验记录。组件语义、无障碍、异步任务和权限仍分别由既有规范裁决。

## 按任务分配空间

| 适用条件 | 规则 | 可省略或降级 | 重新评估条件 |
| --- | --- | --- | --- |
| 用户反复切换对象、调参并核对输出 | 把当前对象和输入、主结果、次要参数各归到稳定区域。宽屏可并排，结果获得主要空间，运行入口靠近输入。窄屏保留对象、结果和主操作，其余面板经可见入口按需打开。`N3` | 任务线性且输入少时用一列，参数就地呈现 | 需要频繁往返，或开始对照多次结果 |
| 多个账号、项目或环境共享同一组页面 | 把范围切换放在壳层，当前范围与页内导航各有独立标识。切换范围时只保留对新范围有效的页面与选择，窄屏仍能辨认并切换范围。`L2` | 单范围产品可省略切换器，保留必要身份线索 | 接入第二个范围，或引入跨范围深链 |
| 用户在列表与详情间频繁往返 | 宽屏可用主从布局并标记当前项。窄屏如能保留有效工作空间，可将两区上下排列。空间不足时改用列表到详情的路径，提供可见返回入口，并按任务需要恢复列表位置、查询和选择。`L3` | 详情很短且只读时可就地展开 | 详情出现独立操作、深链或长内容 |
| 概览用于判断对象健康或继续处理 | 将身份、状态和对应操作放在一起。同口径指标合组，趋势与明细各承载不同问题，从摘要直接进入相关记录。`L2` | 没有独立诊断价值时可省略趋势或概览，从主要任务起步 | 用户反复从多个页面拼凑状态，或新增需定位的异常 |
| 展示面需要让用户理解或挑选成果 | 用代表性成果承担主要视觉，用标题、留白和少量操作说明下一步。展示与工具共享令牌语义，展示专用排版与动效限定在对应页面。`N1` | 纯内部工具可省略展示层，示例可放在首次使用的空态 | 出现公开展示、案例浏览或作品选型任务 |

## 把视觉取舍落实到语义令牌

按[设计系统与令牌规范](design-system-spec.md)接入现有架构。下表的名称描述角色，由目标项目映射到实际令牌。采用同一套角色的组件可随主题换值，角色及交互含义保持一致。`N2` `L1`

| 适用条件 | 规则 | 可省略或降级 | 重新评估条件 |
| --- | --- | --- | --- |
| 页面包含外壳、工作区与浮层 | 先用底色、主面、弱填充和必要分隔表达层级。相邻内容按任务合组，边界和抬升留给需要独立阅读、滚动、操作或遮挡的区域 | 单面任务可用底色与分隔直接组织内容，省略嵌套卡片 | 边界、独立滚动或浮层归属变得难以辨认 |
| 同屏有多个操作、选中和业务状态 | 分开定义主操作、选中、焦点及状态的语义角色。中性主按钮可建立层级，品牌强调色用于需要定位的交互。业务状态结合文字或图标，危险操作沿用已有风险规则 | 品牌强调弱时可用中性色表现选中，仍保留可辨认的焦点和状态 | 新增状态、第二个品牌或需要区分的数据系列 |
| 工具面需要紧凑阅读 | 正文与控件用稳定的无衬线角色，数字列、时间、标识符和代码按比较需要使用等宽数字或等宽字体。展示面可为标题引入衬线角色，并核对中英文回退、行高和截断 | 无展示面可省略衬线角色，无比较需求的自然语言数字沿用正文 | 接入另一种语言、长标识符或并列数据 |
| 控件组采用胶囊形 | 可用于短动作、状态标签和紧凑分段选择。分别保留 Button、状态文本和 Tabs 等正确语义，并用选中指示、焦点与动作文案区分外形相近的控件 | 长标签、密集表单或尺寸受限时改用目标产品已有的紧凑形态 | 长文案、触控或键盘走查出现误判、截断或难点按 |
| 启用多主题、低对比层级或半透明材质 | 按实际叠放关系校验文字、控件边界与状态指示的对比度。玻璃、投影只在需要表达遮挡和浮起的区域使用，背景复杂时提供稳定底色 | 单主题可只交付一套映射。静态实底足以表达层次时可省略透明材质 | 新增主题、图像背景、浮层或对比度回归 |

一份可实现的约定应给出角色 → 令牌 → 使用位置，例如「外壳 → 次级表面 → 顶部范围栏」「主面 → 默认表面 → 会话正文」「弱填充 → 选中背景 → 当前会话行」。已有令牌足以覆盖时复用其命名。若换肤、增加组件或自动检查需要核验，再维护映射表与配对样张。

需要对齐案例风格时，先用「中性壳层包住主要工作面，弱分隔组织信息，少量颜色标记状态和交互」起样。纯工具面将装饰性点阵、媒体拼贴和衬线大标题留给成果展示或首次引导。任务内容已经提供足够辨识度时，可省略这些表现，新增展示或引导任务时再评估。`N1` `L1`

## 让工作状态留在任务上下文

| 适用条件 | 规则 | 可省略或降级 | 重新评估条件 |
| --- | --- | --- | --- |
| 常用操作跨多个页面且用户会重复执行 | 提供可见的搜索或命令入口，按用户语言组织对象与目的地，给常用项标注真实可用的快捷键。输入、中文输入法组字或冲突的浮层打开时，让编辑和当前浮层优先处理按键。`N3` `N4` | 少量入口且导航足够直接时可省略 Command Palette，用局部搜索或原有导航 | 重复跳转成本上升，或可搜索对象明显增多 |
| 用户需要复核、重现或排查一次执行 | 结果默认优先，同一对象内按需提供请求、响应、代码或日志。区分编辑中的参数与本次执行的快照，凭据及敏感数据按权限遮蔽。`N3` | 用户只需交付结果且无需追溯时，可省略原始载荷和代码，保留必要的结果或错误说明 | 新增复现、排障、交接或审计任务 |
| 配置项有清楚的常用与进阶层次 | 默认展示完成任务所需字段，进阶项按需展开。已修改的隐藏值影响结果时，折叠状态仍提示改动并提供重新展开或恢复默认的入口。`N3` | 所有字段都需要一起核对，或进阶项实际使用频繁时可平铺 | 用户反复展开，或折叠后发生由隐藏值引起的误操作 |
| 结果异步返回或需要前置条件 | 在发起处说明缺少的前置条件，在结果区保持状态与对象关联。能确认进度时呈现进度，失败或结果未知时按实际可用能力提供下一步。动效只作补充，减少动效时保留静态状态、文字及操作。`N3` `N5` `L2` | 同步且结果立即可见时可省略独立运行记录和动效 | 延迟、并发、离开后恢复或排障成为任务的一部分 |
| 设置修改会影响正在工作的对象 | 在对象范围内呈现修改和保存反馈，说明生效条件。表单较长且保存入口离开视口时，可按需固定保存区，并保留可见焦点与失败反馈。`L4` | 短表单可把操作放在表单末尾。自动保存仅在语义清楚且能反馈同步、失败及恢复时适用 | 设置跨区、离开时易丢失，或生效条件改变 |

相关行为按[导航与数据浏览](navigation-and-data.md)、[操作与表单](operations-and-forms.md)、[状态与业务流程](states-and-workflows.md)及[组件交互设计语言](component-interaction-language.md)核对。

## 把参考变成可验收的约定

1. 用户给出参考项目时，分别记录设计意图、当前源码与线上观察。结论写到具体页面、状态或组件，出现差异时按证据类别分别记录。
2. 需要迁移一套风格时，选一条代表性任务做样张，交付页面区域、令牌映射、状态与窄屏变化。重复消费的界面把适用角色纳入组件规范。单页小改可直接评审该页。出现第二个消费面时复查是否需要共享样张。`N2` `N5` `L1`
3. 进入实现验收时，用浏览器核对实际采用的主题、视口、输入方式与状态。检查读者能否识别当前对象、主操作和运行状态，缩窄后是否能取回隐藏面板，减少动效后反馈是否完整。无法触发的状态标注证据范围，待具备环境时补验。

示例：在多环境任务控制台中，页头保留环境切换与当前环境，主区以任务列表和详情为主。选中任务后先看结果，再按需打开请求或日志。窄屏由列表进入详情并可返回，运行中保留文字状态。若系统只有单环境且任务同步结束，可省略范围切换与运行记录。接入第二个环境或出现可恢复的长任务时分别复查。
