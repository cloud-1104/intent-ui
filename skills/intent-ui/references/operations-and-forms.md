# 操作与表单

目录：操作契约、交互容器、新增编辑、表单校验、状态操作、删除归档、批量、导入导出和附件。

## 操作契约

每种实际提供的操作至少明确：作用对象和范围、可执行条件、提交语义、进行中状态、成功事实、失败恢复、结果未知时的查询路径。确认框只在有必要理解风险或前置条件时使用。

页面级操作作用于整个集合或当前对象；行操作作用于单条记录；批量操作作用于明确选择集合。避免同名按钮在不同入口有不同范围。可参考 [全局操作](https://cloudscape.design/patterns/general/actions/global-actions/)，布局仍服从当前产品约定。

## 选择交互容器

| 情况 | 优先选择 | 应避免 |
| --- | --- | --- |
| 一个独立、低影响、经常调整的属性 | 行内编辑，明确保存和取消 | 相关字段需要联动却分别自动提交 |
| 短小且需保留列表上下文的操作 | 轻量面板、抽屉或简单弹窗，按现有系统约定 | 容器套容器和长表单挤入确认框 |
| 多字段、说明较多、需要分享或长时间编辑 | 独立页面 | 关闭容器就丢失长时间输入 |
| 有逻辑阶段和依赖关系的复杂配置 | 分步流程，保留前面输入并有复核 | 单靠字段数量机械拆步 |
| 需要理解后果的危险动作 | 短确认对话框，写明对象、影响和动作 | 所有操作一律“确定吗” |

Cloudscape 的[创建模式](https://cloudscape.design/patterns/resource-management/create/)和[编辑模式](https://cloudscape.design/patterns/resource-management/edit/)提供选择依据。本 Skill 允许沿用现有抽屉模式，不把 Cloudscape 的字段数阈值照搬为通用标准。

## 新增、复制和编辑

- 新增只在当前系统承担创建职责时提供。外部同步对象说明来源，提供真实可用的同步或跳转路径。
- 新增和编辑在标题、按钮和提交语义上可辨认；组件复用不等于界面语义混合。
- 默认值只用于有可靠依据的选择；可能改变权限、范围或成本的默认值必须可见。
- 复制是创建新对象：重新处理唯一标识、权限、密钥、状态和关联关系，不把原对象的生效状态直接复制过去。
- 编辑明确可变字段、只读字段及原因。重要生效配置按需展示前后差异，不为普通姓名修改强加复杂复核。
- 有关联依赖时，告知修改影响；如果业务要求新版本、修订或补偿动作，用对应流程，不能用通用编辑绕过。
- 保存成功后更新可见数据并回到合适位置；若当前筛选下对象已不可见，说明原因并给定位途径。
- 保存失败保留输入并显示可恢复原因；并发冲突、权限变化和结果未知按状态规则处理。
- 自动保存仅在业务支持、保存状态清晰且恢复可靠时采用；显示保存中、已保存或失败。不能同时让用户猜测“自动保存”和“保存按钮”各保存什么。

## 表单和未保存修改

- 字段有可见标签、适用的必填标记、格式和限制；占位符不承担唯一标签。
- 条件字段随依赖显示，并明确隐藏值是保留、清空还是不提交。过期或不适用的隐藏值不能悄悄生效。
- 初次打开不把整表立即标红；在用户离开字段或提交时给出适当校验，纠错时及时更新提示。
- 字段错误靠近字段；跨字段或服务端整体错误在表单内说明。提交校验失败后引导到首个相关错误，保留其他输入。
- 通常允许点击提交以暴露校验结果，不用永久灰色按钮让用户猜漏了什么。执行中、无权限、明确前置条件或高风险输入确认未满足时，可以禁用并说明。
- 提交期间阻止重复操作，同时保留无关区域的可用性。取消编辑、关闭窗口和取消正在运行的后台任务是不同动作。
- 仅有真实未保存变化时拦截可能丢失修改的离开；提供“继续编辑”和“放弃修改”。业务支持时可增加保存草稿；已保存后不继续拦截。
- 原生浏览器离开确认能力有限，不承诺可自定义全部浏览器关闭文案。不能依赖它作为唯一恢复措施。

Cloudscape 依据：[校验](https://cloudscape.design/patterns/general/errors/validation/)、[未保存修改](https://cloudscape.design/patterns/general/unsaved-changes/)。自动保存及隐藏字段语义为业务适配。

## 停用、启用及其他状态动作

**前提**：业务存在这些状态及转换。不要给订单、日志等对象机械添加“启用开关”。

- 文案使用具体业务动词：停用账号、暂停任务、取消订单、下架内容；明确不同动作的后果。
- 说明影响新业务、已有业务还是两者，以及生效时间。保留历史查询不等于业务仍可继续使用。
- 低影响、即时、可逆的布尔状态可用开关；需解释后果、等待执行或填写原因时使用动作按钮和必要确认。
- 在服务端确认前显示处理中，不把开关已变色当作完成。失败恢复真实状态；结果未知时查询结果而非盲目翻转重试。
- 恢复或启用重新检查权限和依赖；没有恢复能力时不得展示可恢复承诺。
- 状态转换还包括发布、撤回、归档、暂停等；为每种转换列出来源状态、目标状态、角色、前置条件、执行中状态和失败去向。

这是本 Skill 的业务生命周期扩展；Cloudscape 的[操作组织](https://cloudscape.design/patterns/general/actions/global-actions/)可用于安排入口。

## 删除、移除和归档

先确定语义：删除销毁或删除对象；移除解除关系；归档退出日常工作集合；停用暂停使用。软删除也不自动意味着用户能恢复。

| 风险情况 | 推荐交互 |
| --- | --- |
| 低影响、容易重建或实际可撤销 | 可直接操作并清楚反馈；存在撤销能力时才提供撤销 |
| 难以重建、有明显影响但范围清晰 | 确认对象、后果和可恢复性，使用具体动作按钮 |
| 严重、不可逆或有级联影响 | 提供影响摘要及前置条件；确有必要时要求输入对象名等额外确认 |
| 被引用、处理中或业务禁止 | 阻止并解释约束，提供有权限且有效的处理路径 |

- 确认内容包含对象标识、数量和影响，不能只有“确定删除吗”。
- 显示依赖时只展示用户有权知道的信息；确认后仍需重新检查当前条件。
- 取消确认不产生修改。删除成功后从当前视图移除或标明实际状态；异步删除先显示待删除。
- 不把本地隐藏行当作删除成功；部分失败分别报告。重试前确认哪些对象仍未完成。

风险分层参考 Cloudscape 的[删除模式](https://cloudscape.design/patterns/resource-management/delete/)；具体依赖、恢复和保留规则由业务决定。

## 批量操作

**条件必需**：存在重复处理任务且业务允许批量化。选中多行不意味着所有动作都适合批量。

- 明确选择的是本页、跨页已选记录还是所有匹配结果；展示数量，切换全量范围须显式操作。
- 处理混合权限、状态和依赖：全有或全无，或仅处理符合条件的记录。必须在执行前说明策略和不符合的数量，不静默跳过。
- 有副作用的操作绑定确定的对象集合或明确的执行时查询规则；搜索结果变化不能无声扩展作用范围。
- 执行后显示成功、失败、跳过数量及失败项原因。全有或全无的业务不展示虚假的局部提交。
- 只对适合重试的失败项提供重试，避免重复处理已成功记录。需要逐条判断的审批不为了方便而批量通过。

这是后台扩展规则，需与具体接口的事务、权限和任务能力对齐。

## 导入、导出与附件

**导入**：说明支持格式、字段、重复记录处理和大小限制；需要复杂映射时提供样例或模板。执行前按风险预检、预览和确认影响。结果说明总数、成功数、失败数及可定位的行或字段；部分提交规则明确。文件上传成功与业务导入成功分别反馈。

**导出**：执行前明确数据范围、字段和必要的时区；区分当前页、已选记录和全部匹配。按权限限制敏感字段。长任务提供状态与下载入口，只有服务确有过期机制时显示真实有效期；不把“生成任务已提交”写成“文件导出完成”。

**附件**：上传前展示类型和大小约束；逐项显示进度、失败和可重试状态。移除待上传文件、解除附件关联和删除原文件分别命名。预览不支持时给出有效下载或说明，不能渲染一个可点击但无效果的入口。

导入导出和文件能力均按任务决定，不是所有表格或详情页的默认配置。上述规则是通用后台扩展。
